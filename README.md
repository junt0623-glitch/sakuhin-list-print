# 作品リスト印刷工房

展覧会の作品リスト（Excel・スプレッドシート）を、配布用の A3両面印刷1枚に組むツールです。ブラウザで `index.html` を開くだけで使えます。

## 使い方
1. 「Excel / CSV を読み込む」で作品リストを読み込む（1行目は見出し）。スプレッドシートからの貼り付けも可。
2. 見出しは紙面をクリックして直接書き換える。書体・大きさ・配置は左の「2　見出し」で調整。
3. 「画像を追加」で展示室平面図を入れる。枠の大きさは紙面上でドラッグして調整。文字も追加できる。
4. 「印刷する」→ 用紙 A3・横・余白なし・倍率100%・両面「短辺で綴じる」。

作品リストの文字は 12pt を上限に、両面1枚に収まる大きさへ自動で調整します（最小 9pt）。
